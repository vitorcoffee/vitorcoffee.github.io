Welcome. This is a personal site built with [Hugo](https://gohugo.io) and the
[Blowfish](https://blowfish.page) theme. The repository is bootstrapped with
a GitHub Actions workflow that builds the site and ships it to
[vitorcoffee.github.io](https://vitorcoffee.github.io/) on every push to
`main`.

Browse the [Posts](/posts/) section for examples of Markdown rendering,
shortcodes, and a few short reading lists. Replace anything you don't want to
keep; the framework and theme are already configured.

To add a new post from the command line (requires Hugo installed locally):

```bash
hugo new content/posts/my-next-post.md
```

Drop a Markdown file in `content/posts/` and push — that's it.
