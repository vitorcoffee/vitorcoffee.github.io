I'm Vitor, a backend engineer. I work mostly with services that other
services depend on, and I write here about the parts of that work that
are worth keeping.

## What you'll find here

- **Engineering notes.** Code reading, debugging stories, and design
  write-ups from real systems.
- **Reading lists.** Papers and posts I keep coming back to.
- **Occasional meta posts.** Tooling, site infrastructure, and the
  occasional detour into something that isn't strictly backend.

## Stack behind the site

- [Hugo](https://gohugo.io/) for static generation
- [Blowfish](https://blowfish.page/) as the theme
- GitHub Pages for hosting, deployed via GitHub Actions
- The source repository is public on
  [github.com/vitorcoffee/vitorcoffee.github.io](https://github.com/vitorcoffee/vitorcoffee.github.io)
